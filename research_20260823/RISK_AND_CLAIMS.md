# Risk and claims register

| Risk / prohibited claim | Why it matters | Control |
|---|---|---|
| “The whole salon provides X” | The booking page lists distinct named practitioners; relationship/employment is not verified. | Keep concept hair-led; name or feature others only after confirmation. |
| Medical, therapeutic or cosmetic-result claims | The profile lists aesthetics and laser-related services, but the evidence is a booking category, not clinical efficacy, qualification, suitability or regulatory evidence. | Exclude those services and all efficacy/safety claims. |
| “Olivia will see this email” | The email is public but generic and mailbox delivery/owner access are unknown. | Public Business Email PASS; Deliverability UNKNOWN; Decision-maker Reach GENERIC. No outreach authorisation. |
| “No website” stated as absolute | A bounded search did not verify a standalone domain. | Use `NO OWNED WEBSITE VERIFIED` with search boundary/date. |
| Review/rating claims | A visible count is not an audited rating; individual text may change. | State only the observed count/date in internal evidence; recheck before any public use. |
| Image/logo reuse | Public availability does not establish copyright, model, photographer, trade-mark or client permission. | Keep `CUSTOMER AUTHORIZATION: NOT VERIFIED`; use only appropriately authorised assets or new truthful concept visuals under later authority. |
| Price/availability claims | Booking data changes. | Treat as volatile; no static price or availability claim without fresh recheck and confirmation. |
| £600 as an affordability conclusion | Review volume, operations and specialised consultation are signals, not financial evidence or purchase intent. | Say “commercially plausible to test,” never “can afford/will buy.” |

Residual risk: meaningful presentation value is supported, but there is no current trigger or purchase-intent evidence. This weakens prioritisation but does not negate the narrow static opportunity.
