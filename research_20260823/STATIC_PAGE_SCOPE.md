# Static one-page scope

## Recommended concept boundary

**Lavella Hair Limited in Weston: colour, bespoke hair extensions and hair-replacement consultations.** This reflects the company-controlled booking categories and Olivia's hair-extension brand path. [SRC-02, SRC-04]

### Shown in a future concept (only if separately authorised)

- Hero: Lavella Hair Limited, Weston/Hitchin area, hair colouring and bespoke extension/replacement consultations.
- Three factual service groups: Colouring; Hair Extensions & Replacement Solutions; Blow Dry / Barbering only if rechecked on the live booking page at production time.
- Short process/reassurance: consultation → tailored plan → external booking. The “tailored plan” wording is directly supported for the two extension consultations.
- Proof: visible review volume with careful, current source attribution; no invented score or outcomes.
- Location, public contact details and one external Ovatu `Book now` CTA.

### Reserved / excluded from the concept

- Timetable, availability, customer login, payment, gift vouchers, waiting list and all booking steps (remain on Ovatu).
- Any self-hosted form, CMS, database, authentication, ecommerce, payment or analytics/tracking.
- Aesthetics, injectable/medical claims, laser treatment, SPMU/tattoo, massage, nail, lash and third-party practitioner service claims unless the actual client confirms the commercial relationship and copy.
- Current booking prices, availability and individual provider details unless freshly verified and client-approved.

## Gate analysis

- H4 static single-page fit: PASS, because the proposed page solves presentation, service discovery and trust while retaining the existing booking provider.
- H5 evidence-backed Demo basis: PASS; the current owned presentation omission is directly reproducible at SRC-01/SRC-02 in desktop and 390px browser review.
- H6 exclusion: PASS only for the narrow hair-led scope. It would FAIL if asked to replace the booking platform or represent the entire mixed practitioner directory.

Proposed CTA: **Book a consultation** → existing `https://lavellahairlimited.book.app/book-now`. This directs clients to the real booking provider without implying availability.
