# Website opportunity

## Current state

`TRACK N — NO OWNED WEBSITE VERIFIED` / `Website status: NO OWNED WEBSITE VERIFIED`.

Three checked public surfaces were: merchant-controlled Ovatu profile (SRC-01), Olivia's Linktree (SRC-04), and exact-name/location search (SRC-08). They route visitors to platform pages rather than an attributable custom-domain site. This is a current research finding, not a claim that no website can exist.

## Observed presentation gap

At Desktop and approximately 390px, the Ovatu home page exposes a logo, booking, location/contact and reviews, but does not introduce a concise salon proposition or explain the principal hair categories before the visitor must enter the booking flow. The mobile header collapses the routes behind a menu, and the initial content still starts with booking/location rather than a service-led narrative. The booking page is useful operationally but presents a long mixed-provider category list. [SRC-01, SRC-02]

This is a real owned-presentation gap rather than an assertion that Ovatu is broken. Ovatu should remain the booking system.

## Meaningful static upgrade

A polished static page can honestly provide, before its one external `Book now` link:

1. A Lavella Hair/Weston proposition centred on colour, bespoke extensions and hair-replacement consultation;
2. a clearly separated “at the salon” directory only if the client confirms each practitioner and wording;
3. selected, attributable proof (the visible review count and narrowly quoted/reproduced review only after source and permission review);
4. location/contact and the existing external booking path.

H0.5: `PASS — MEANINGFUL DEMO OPPORTUNITY VERIFIED`. The transformation is feasible in 30–60 minutes only when it is limited to verified hair-led scope, does not recreate booking, and does not represent co-located practitioners as Lavella employees.

## Commercial assessment

Website relevance to customer acquisition: `MEDIUM`. The booking flow and social/link-in-bio routes already create a path, but a local client deciding among specialised hair/extension providers benefits from clearer pre-booking service and trust context. `NO CLEAR TRIGGER FOUND`; no public evidence shows a current redesign purchase intent.

Business-specific website leverage: `MEDIUM`. A £600 static page is commercially plausible for a 411-review, specialised hair business with paid booking operations, but it is not a proven ability or willingness to buy.
